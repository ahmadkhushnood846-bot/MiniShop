# MiniShop

MiniShop is a responsive e-commerce web application built with React.

## Features

- Responsive design
- Product listing
- Product search
- Category filtering
- Product details
- Add to cart
- Increase and decrease product quantity
- Remove products from cart
- Cart item count
- LocalStorage cart persistence
- Checkout form
- Form validation
- Order placement
- Order success page
- Responsive navbar and footer

## Tech Stack

- React
- JavaScript
- React Router
- CSS
- Vite
- LocalStorage

## Pages

- Home
- Products
- Product Details
- Cart
- Checkout
- Order Success
